The machines that make the libraries, usable from a browser, a terminal, or inside Renoise.

Wavetable builder

Turns wavetables into gate-scan instruments three ways: a browser page that runs the whole conversion client-side, a Python CLI for whole collections, and a Lua tool that builds from samples already inside your song. The XML it writes is validated against the schema Renoise ships.

Phrase To Pattern

Renders the phrases triggered in a pattern into real, editable note data. The phrase bank is left untouched, existing note cells are never overwritten, and it is one undo step. Handles Keymap and Program triggering, Key Tracking and LPB scaling.

YT Sampler

Paste a YouTube URL and an optional time range, and the audio lands in the Sample Editor. The tool hands the download to a detached script and polls it, so a two-hour job leaves Renoise fully playable.
